## 🇹🇷 Hakkımda / 🇬🇧 About

Windows üzerinde geliştirici deneyimi ve **agent-aware** terminal araçları tasarlıyorum. **D Brand** çatısı altında yayınladığım projeler şu üç eksende ilerliyor:

- 🤖 **AI-native dev tools** — komut hattı + büyük dil modeli + paralel pane orkestrasyonu
- 🪟 **Native Windows performansı** — Tauri 2, Rust, ConPTY, Job Object sandboxing
- 🎨 **Disiplinli UX** — frameless pencere, ince tipografi, çift dil (TR + EN) varsayılan

**Öne çıkan özellikler / Highlights**

- 🤖 **AI Agent Watch** — pane başına AI tool-kullanım gözlemcisi, OSC 9999 protokolü, canlı maliyet rozeti
- 🎯 **ARM64 + x64 çift mimari** — Surface Pro X, Snapdragon laptop'lar dahil
- 🔄 **Merkezi güncelleme sistemi** — 3 mod (silent / passive / full UI), auto-start on boot
- 🪟 **Frameless pencere + Job Object** — child process'ler tek noktadan denetlenir, parent crash'inde otomatik temizlenir
- 📊 **Canlı DFetch** — gerçek zamanlı CPU/RAM/disk istatistikleri, tema uyumlu overlay
- 🌐 **17 dil hazır** — TR/EN tam çeviri, 15 stub topluluk PR'larıyla doluyor
